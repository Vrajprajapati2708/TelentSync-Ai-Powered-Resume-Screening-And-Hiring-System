## 2. Major User Journeys & Views

### A. Candidate Journey
1. **Landing Page (`#landing`)**: Hero banner, live stats counter, features, workflow, testimonials.
2. **Authentication (`#login`, `#register`)**: Role selector tabs (`candidate` vs `hr`), form submission.
3. **Candidate Dashboard (`#cand-dash`)**: Top metrics (ATS Score, Applications, Profile Views), 7-day activity chart, quick upload card.
4. **Resume Upload (`#cand-upload`)**: Drag-and-drop zone, file input, upload list (`renderUploadHistory`), guidelines card.
5. **Resume Analysis (`#cand-analysis`)**: Contact info table, technical skills tags, Chart.js radar chart, project grid.
6. **ATS Diagnostic (`#cand-ats`)**: Animated SVG circular score ring, matched keywords badge, missing keywords badge, ATS suggestion cards.
7. **Job Matches (`#cand-jobs`)**: AI match score cards, Clearbit/Google logos, matching skill pills, "Apply Now" action.
8. **Candidate Profile (`#cand-profile`)**: Bio, summary, phone, location, LinkedIn/GitHub URLs.

### B. Recruiter / HR Journey
1. **HR Dashboard (`#admin-dash`)**: Overview KPI cards (Total Applicants, Shortlisted, Avg ATS, Active Jobs), hiring funnel chart, recent applicants table.
2. **Candidate Management (`#admin-candidates`)**: Applicant table with rank badges, outlier alerts, cluster badges, status filter dropdowns.
3. **Candidate Detail Modal (`#view-cand-modal`)**: Modal displaying applicant profile, skills, match score, and Shortlist/Reject action buttons.
4. **Talent Clusters (`#admin-clusters`)**: Visual clusters generated by KMeans clustering.
5. **Job Vacancies Management (`#admin-jobs`)**: Active jobs list, job creation modal, job deletion.
6. **ML Pipeline Monitor (`#admin-pipeline`)**: Status of spaCy NER model, TF-IDF vocab size, training trigger button.
